C#-is kasutatakse `$` märki string interpolation jaoks ehk muutujate lisamiseks teksti sisse.

Näide ilma `$` märgita:

```
string nimi = "Ott";
int vanus = 17;

Console.WriteLine("Minu nimi on " + nimi + " ja olen " + vanus);
```

Näide `$` märgiga:

```
string nimi = "Ott";
int vanus = 17;

Console.WriteLine($"Minu nimi on {nimi} ja olen {vanus}");
```

Mõlemad väljastavad:

```
Minu nimi on Ott ja olen 17
```

Pea meeles:

- `$` pannakse jutumärkide ette.
- `{ }` sisse kirjutatakse muutuja või arvutus.
- `$` teeb muutujate lisamise teksti sisse lihtsamaks.

Näiteks `Console.WriteLine($"Vastus on {5 + 5}");` väljastab `Vastus on 10`.

C#-is kutsud ehk call'id meetodit välja, kirjutades meetodi nime ja sulud ().
1. Meetodi loomine
static void Tervita()
{
    Console.WriteLine("Tere!");
}


2. Meetodi kutsumine (calling)
Tervita();


3. Täielik näide
static void Main(string[] args)
{
    Tervita();
}

static void Tervita()
{
    Console.WriteLine("Tere!");
}


Väljund:
Tere!


4. Meetod parameetriga
Meetodile saad anda ka väärtuse.
static void Tervita(string nimi)
{
    Console.WriteLine($"Tere, {nimi}!");
}


Kutsumine:
Tervita("Ott");


Väljund: Tere, Ott!
5. Pea meeles
Mõiste	Tähendus
static void	Meetod, mis ei tagasta väärtust
Tervita	Meetodi nimi
()	Meetodi sulud
string nimi	Parameeter
Tervita("Ott")	Meetodi väljakutse
